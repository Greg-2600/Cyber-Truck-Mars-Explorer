# Cyber Truck: Mars Explorer

A 3D interactive driving game built with [Three.js](https://threejs.org/) where you pilot a Cyber Truck across the Martian landscape.

## 🎮 Play Online

Visit the [live demo](https://your-username.github.io/cyber-truck-mars/) to play in your browser.

## 🕹️ Controls

- **Arrow Keys** or **WASD** - Drive forward/backward and turn left/right
- **Space** - Accelerate
- **Shift** - Brake

## 🌍 Features

- Fully 3D Mars environment with procedural terrain
- Realistic physics and collision detection
- Dynamic lighting and shadows
- HUD display showing speed and position
- Smooth camera controls

## 📋 Requirements

- Modern web browser with WebGL support
- No installation needed - play directly in your browser

## 🛠️ Development

### Project Structure

```text
├── index.html      # Main HTML file
├── game.js         # Game logic and Three.js scene
└── README.md       # This file
```

### Running Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/cyber-truck-mars.git
cd cyber-truck-mars
```

1. Start a local web server:

```bash
# Python 3
python -m http.server 8000

# Or Node.js (if you have http-server installed)
npx http-server
```

1. Open `http://localhost:8000` in your browser

## 🎨 Customization

- Modify terrain in `game.js` to change the Mars landscape
- Adjust camera settings to change the driving perspective
- Tweak physics values for different handling
